# Use Cases

## Suitable current uses

### Processing regression tests

Compare a known reference with a candidate output and fail CI when expected
visual processing disappears.

### Missing-frame detection

Detect frames in which a normally persistent transformation is absent.

### Evidence generation

Produce annotated media and tabular reports for engineering review.

### Pipeline smoke tests

Confirm that a processing stage creates measurable visual change.

## Future uses requiring target-aware support

- Face anonymization coverage
- Licence-plate anonymization coverage
- Document redaction checks
- Required-region pixelation
- Per-object continuity analysis

## Unsuitable claims

The current release should not be described as:

- A guaranteed anonymization validator
- A semantic object detector
- A legal compliance certificate
- A forensic authenticity system
- A replacement for high-risk human review
